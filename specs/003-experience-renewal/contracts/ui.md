# Hợp đồng UI

- Mọi trang vẫn truy cập được qua navigation, dialog có nhãn, lỗi có thông báo và thao tác phục hồi.
- Dashboard chỉ dùng summary thực; onboarding dựa trên ví/budget/sổ/khoản đến hạn. Số dư là hiện tại mọi thời gian; income/expense theo tháng, saved không cộng vào tài sản.
- Ctrl/Cmd+K focus tìm kiếm; menu mobile đóng Escape và giữ focus; tooltip tiền lấy chuỗi gốc.
- Tắt motion theo thiết bị hoặc hệ điều hành, không trì hoãn số tiền để chạy hiệu ứng.
- API thêm lifecycle/filter/profile ở [004](../../004-planning-lifecycle/contracts/api.md).
